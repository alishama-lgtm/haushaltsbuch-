# Unser Haushaltsbuch

Haushaltsbuch als Webseite: Zahlungen, Fixkosten, Wochenbudget, Sparbetrag und Monatsplan.

**Alle Daten bleiben auf dem Gerät** (im Browser-Speicher). In diesem Repository liegt nur der
Programmcode, keine Zahlen. Sicherung und Wiederherstellung über Einstellungen → Sicherung.

Am iPhone: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
